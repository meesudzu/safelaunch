# plans/

Implementation plans produced by `superpowers:writing-plans`.

## Naming

`YYYY-MM-DD-<topic>-plan.md`

## Lifecycle

1. `writing-plans` writes a phased task breakdown here, sourced from an approved
   design in `../specs/`.
2. `using-git-worktrees` sets up the branch.
3. `subagent-driven-development` (or `dispatching-parallel-agents`) executes the phases.
4. Once the work ships, the plan stays for audit.
